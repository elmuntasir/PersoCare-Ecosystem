# Roadmap (ideas, not commitments)

This file holds ambition, deliberately separated from `present/` so it
can't quietly expand today's scope. Nothing here has a due date or an
architecture yet. See `docs/README.md` for the promotion rule.

## Phased build order (the one part of this file that is a real sequencing plan)

1. **Web platform** (admin, doctors, patients) — proves the product.
2. **Mobile app** (patients first, then doctors if needed) — extends
   accessibility.
3. **Desktop Workstation** — only when a real hospital customer needs
   hardware integration (printers/scanners/card readers), not before.
4. **AI Marketplace and ecosystem expansion** — once real organizations
   are using the platform.

## Longer-term module ideas (unordered, unscoped)

- Insurance (as another tenant type)
- Pharmacy networks
- Ambulance services
- Wearable integration / remote patient monitoring
- Government health service integration
- Medical education
- Research collaboration
- Clinical decision support
- Community-created AI marketplace agents with creator revenue sharing
- Advanced/specialized AI services beyond the three current models
  (BYOK, marketplace agents, organization AI)

## Positioning idea (not a spec)

The broader ambition discussed: becoming connective tissue across
booking (Practo-like), trust/reviews (Healthgrades-like), and
AI-native clinical tooling — rather than competing directly in any one
of those categories. This is a positioning idea to revisit once there's
real traction, not a justification for building toward all of it now.
