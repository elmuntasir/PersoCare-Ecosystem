# Vision

Build the operating system of modern healthcare — an open, AI-native
ecosystem where every healthcare participant, service, and intelligent
agent can securely collaborate on a single trusted platform.

## The operating principle

> Every architectural decision must increase the platform's ability to
> evolve while decreasing the effort required to maintain it.

This is the test applied to every feature, technology, and package
decision. If a proposal fails either half — it doesn't increase future
optionality, or it increases the maintenance burden without
proportional benefit — it doesn't belong in `present/`.

For the expanded ambition (what this could grow into, module by
module), see `future/roadmap.md`. This file stays short on purpose —
see `docs/README.md` for why.
